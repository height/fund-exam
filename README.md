# 基金从业刷题

基金从业资格考试的刷题 App。一个 HTML 文件，双击就能用，装到手机主屏后能离线刷。
做题记录存在浏览器本地，不上传，没有账号，没有后端。

**[打开用](https://height.github.io/fund-exam/)** · 或者下载 `dist/index.html` 双击

---

## 为什么会有这个

市面上的刷题 App 要么要注册、要么要会员、要么把解析藏在付费墙后面。
而这门考试的复习其实很简单：一千来道题，看着解析刷完，考前对着章节补弱项。
不需要服务器，不需要账号，不需要把做题记录传给任何人。

所以这个东西只有一个 HTML 文件。1.2 MB，题库、解析、界面全内联在里面。
扔到任何静态托管都能跑，塞进 U 盘也能跑，飞机上也能刷。

## 有什么

**1071 道真题和押题**，全部带解析（科目一 647 / 科目二 424）。
来源是备考 PDF：临考押题 733 题、模考金题 283 题、2025 年 11 月真题 55 题。

**按官方教材目录归类**——科目一 8 章、科目二 18 章，跟书对得上。
这是这个项目下功夫最多的地方，下面单独说。

**练习模式**：选完立刻出答案和解析，答错自动进错题本。
可以按全部 / 没做过 / 错题 / 章节筛，顺序或随机。答对能自动跳下一题，答错会停下来让你看。

**章节练习和章节考试**：对着教材一章一章推进，或者单章抽 30 题限时考一遍。

**模拟考试**：120 分钟、100 题、60 分及格，按章节题量比例分层抽题。
关掉页面倒计时照走真实时间，回来接着考，到点自动交卷。

**错题本**：答错自动收进来，再答对自动移出去。

**公式攻坚**：31 道计算题专练 + 18 页公式图谱（可放大），右下角挂一个科学计算器。
计算器是自己写的词法分析加调度场求值，不用 `eval`——用户输入直接进 `eval` 这种事不该出现在代码里，
而且单文件 PWA 常部署在带 CSP 的环境，`eval` 会被拦。

**发展时间线**：基金业 1822 至今的 71 个可考时点，分「必背 / 常考 / 了解」三档，
默认只看考试重点。有个「盖住年份」开关，把日期遮起来自测——这门考试的史实题挖的就是年份。

**知识图谱**：考点脉络一张图，章节 → 主题 → 必背要点，逐层点开。

**白话讲解**：99 道解析最薄弱的题另有一份大白话版本，折叠在原解析下方。原解析一字不改地留着，方便核对。

**AI 解析（可选）**：答错时可以让模型换个讲法，也能生成一页交互式图解。
支持 DeepSeek / 智谱 GLM / ZenMux，各存各的 Key，Key 只存本机浏览器，只发给你自己填的那个接口。
不配也不影响刷题，只是少一个功能。

**语音朗读（可选）**：念题干和解析，语速 0.75×–2× 可调，同一段话重播走缓存不重新合成。

## 章节归类是怎么做的

原来的章节标签是关键词猜的，1071 题里有 257 题堆在「综合」，等于没归类，
而且标签不是教材章名，对着书复习根本用不上。

重做的时候用了三轮交叉复核：

1. **归类**——题库切成 28 片并行处理，每片独立归类
2. **复核**——另一批人手拿到同一批题独立核对，只挑明确归错的
3. **裁定**——有分歧的逐题重判，必须给出教材出处

复核这一层不是走过场。有一片 40 题只回来 39 条，被吞掉的那道「基金信息披露的主要作用」
是第十七章的标准考点。这种漏题在界面上根本看不出来——章节页只会少一题，没人会去数。
只跑一遍就漏了。

之后又挑出 120 道归类时被标「拿不准」的题重查一遍，这次不给现有答案（避免顺着确认），
盲判完再比对：81 题两个独立判断撞上，39 题有分歧，另外揪出 10 题是被一份错误的参考资料带偏的
（教材把杜邦分析放第三章，那份资料写成第四章，有人查到了正确答案又推翻了自己）。
最后 47 题改判，1 题存疑并单独标注。

落盘前有一道硬校验（`tools/apply_chapters.py`）：漏题、多余 id、非法或串科目的章名，
任一不过就整体拒绝写入。原因很实际——章名错了只会表现为「章节练习抽出一堆不相干的题」，
用户不会怀疑是标签错了，所以宁可不落盘。

## 跑起来

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/index.html，单文件，双击可开
```

端到端自检，先 build 再真跑一遍要部署的产物：

```bash
python3 tools/test_app.py     # 需要 playwright + 本机 Chrome
```

67 条断言，只驱动界面不碰内部变量，所以重构不会把测试一起带塌。
覆盖了答题、交卷算分、错题进出、断点续练、章节抽题、计算器求值、
配置持久化、朗读缓存这些主路径。

## 项目结构

```
src/
  App.jsx               底部导航 + 视图切换（hash 路由）
  views/                首页 / 练习 / 模拟考 / 错题本 / 设置
                        章节练习 / 公式攻坚 / 知识图谱 / 发展时间线
  components/
    ui.jsx                图标、选项列表、解析块、AI 面板
    Calculator.jsx        科学计算器（底部抽屉，非模态）
    SelectionTip.jsx      划词解释
  lib/
    bank.js               题库读取、统计、分层抽题（纯函数）
    calc.js               表达式求值，手写不用 eval
    db.js                 IndexedDB 封装
    store.jsx             全局状态
    format.jsx            题干 / 解析 / Markdown 排版
    ai.js                 模型调用、TTS、念稿转换
  data/                  由 tools/ 生成，别手改
  styles.css             设计令牌 + 全部样式
tools/                  Python 数据管线
  extract.py              从 PDF 抽题、去重
  taxonomy.json           官方教材目录，章节归类的唯一白名单
  chapters.json           题目 id -> 章名
  apply_chapters.py       校验并写回题库
  test_app.py             端到端自检
```

一共 5800 行左右，依赖只有 React 和 Vite。

## 关于题库

题目 id 是「题干 + 选项集合」的内容哈希，同一道题不管从哪份 PDF 抽出来都是同一个 id。

去重时会丢掉：内容完全相同的题；4-gram 相似度 ≥ 0.85 的近似题；
选项集合和答案都相同、题干相似度 ≥ 0.70 的题；题干一字不差且四个选项中三个相同的题。
重复时保留来源更可信（真题 > 模考 > 押题）、解析更全的那份。

新抽出来的题如果不在归类映射表里，会被标成「未归类」并在抽题日志里列出来，
不会被悄悄塞进某一章。

> 题目来自第三方押题 / 真题回忆资料，考点数字以中国证券投资基金业协会最新正式文件为准。

## 隐私

- 做题记录、错题、考试成绩存浏览器 IndexedDB，不上传
- API Key 存 localStorage，跟做题记录分开，只发给你自己填的那个接口
- 没有埋点，没有统计，没有第三方脚本
- 设置页可以导出 / 导入进度 JSON，换设备自己搬
