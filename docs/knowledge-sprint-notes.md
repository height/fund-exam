# 脑图冲刺笔记

按用户两份讲义和新版章节补充全部 170 组考点：科目一 66 组、科目二 104 组；共 933 条、约 4.3 万字。原有章、节、考点顺序和题目归属不变，不向界面提供讲义页码。

## 内容维护

- `tools/lecture-notes.tsv` 保存原有概述及内部来源定位。
- `tools/lecture-sprint-notes.tsv` 为每组考点补充规则、适用边界和例子。五列依次为科目、考点标题、必背补充、易混易错、理解速记；`^^` 分隔同色条目。
- `npm run update:knowledge` 合并生成 `src/data/knowledge.js`，校验缺失、重复、未知考点和三色内容完整性。构建要求生成结果最新。
- 红笔表示核心必背，蓝笔表示易混易错，绿笔表示辅助理解和记忆。等级是复习优先级，不是命题频率预测。计算例子用于说明公式；法规数字按所提供讲义口径整理。
- 核对中特别区分协会沿革、私募基金与资管计划门槛、工作日与自然日、募集与备案、基金总资产与净资产、收益率与风险指标分母。风险调整指标另核对了讲义中的公式图像；未照搬“夏普与特雷诺数值必然相等”一类不成立的结论。

## 阅读体验

顺序为核心必背、易混易错、理解速记。去掉范围切换、重复颜色图例及辅助说明句；保留分组标题和笔色文字。支持专注阅读、上一/下一考点，以及新增正文关键词搜索。

笔记顶部提供朗读、紧凑的本章练习入口、阅读展开和关闭按钮；底部不再预留练习按钮区。朗读复用既有 Speaker 组件，顺序与屏幕一致，按当前考点 key 挂载以在换考点、关闭或离开时取消旧朗读。沿用用户的语音配置，不修改服务端点或密钥。
