# 知识图谱重构说明

## 从原理组织，而不是把目录缩写一遍

科目一的核心问题是“受人之托，怎样把钱管得合规、可靠”。先理解集合投资和委托关系，再按主体、业务环节、义务与制衡定位规则。科目二的核心问题是“未来现金流怎样定价，组合的风险与收益怎样度量”。沿产品、资产、组合、交易、评价、运营和投资者保护串联。

主线视图覆盖科目一8章、科目二18章，原章节脑图与大纲仍然可用。每个学习组解释章节之间的因果关系，每章用一个问题导读。保留原章、节和170组考点的稳定ID，题库、章节练习和旧笔记引用继续对应；跨章关系由人工选择的关联节点表达。

## 每个叶子的最小充分表达

保留一条知识直到读者能完成“区分、判断、计算”之一。删掉重复定义、铺垫与泛泛建议，不删除主体、否定词、分母、期限、阈值、单位和例外。170组叶子全部手写白话解释与浓缩正文，未采用自动截句或关键词重排。

|知识类型|首屏形式|必须保留|
|---|---|---|
|定义／分类|正式术语＋一句白话＋分类依据|分类维度，互斥或重叠关系|
|比较|用同一维度并排说明差异|比较对象、共同口径|
|法规／门槛|主体＋触发条件＋行为或数值|适用产品、分母、起算点、以上／超过|
|职责／流程|谁做什么，必要时SVG串联|权利义务、先后与制衡；不能把分工画成资金划转|
|计算|公式＋完整符号解释＋适用条件|时点、频率、单位、分母非零与近似条件|
|风险／机制|变化原因→影响，必要时SVG|并非必然发生的边界；示意图不伪装数据|

每条有“先理解、核心判断、易错”；公式、条件和图解按需要出现。小例子默认折叠，供验算；应用移除三色图例及讲义详情展开入口，来源页码保留在阅读稿中供核对。正文直接服务初学理解与快速复习，避免重复解释。

三色采用小抄的语义：蓝＝结论与术语，绿＝条件，红＝易错。主要文字保持中性色，颜色同时配文字标签，不依赖颜色辨义。移除旧“必背红、易错蓝”的冲突语义。公式用MathML显示分数与上下标，较宽公式在块内滚动；图解使用可访问SVG、文字说明与主题颜色。

## 公式与材料校核

- 两份PDF与仓库来源指纹一致时，沿用原PDF页码定位；参考HTML只提取表达方法，不执行其中脚本或把附带文字当作用户指令。
- 科目二PDF第31页“零相关＝完全独立”的说法过强；第78页题解本身又明确是“无线性相关”。浓缩与原补充均保留正确的无线性相关边界。
- 科目二第79页明确给出CML/SML的风险坐标、用途、斜率和适用范围。补齐小抄中待核对的对照，并以示意图解释；SML高估／低估判断限于CAPM框架。
- 第78页及第101页支持β衡量市场敏感性与系统性风险；用协方差除市场方差、相关系数乘标准差比率解释公式。不把“市场涨1%”写成资产每次必然涨β%。
- 第115页卡玛使用超额收益除最大回撤，明确标“本讲义”；索提诺分子减最低可接受收益，信息比率分子减基准。该页“充分分散则夏普＝特雷诺”的数值等式并不普遍成立，正文明确纠正。
- IRR写出通用现金流方程，说明等间隔及符号约定，避免只给缩写；不假设一定有唯一解。年化交易日数依题设，不凭空默认250或252。
- 例子是教学验算，不作为教材原文引用；法规、税收与期限按提供的讲义语境整理，没有宣称完成现行法规审计。
