# 知识图谱 UI 升级

知识图谱保留新版教材的 26 章、113 节、170 组考点和现有题目归属，改为适应桌面与手机的学习工作台。考点详情不展示讲义页码。

## 设计与交互

- 保留现有冷灰、蓝色主题及系统中文字体，支持浅色和深色。仅图谱页使用宽画布，其他页面布局保持原样。
- 默认按章学习；全科总览以双向脑图呈现章节，进入章节后按“章 → 节 → 考点”逐级展开。
- 左侧目录显示章节顺序、节数、考点组数。本章练满 3 题后显示真实正确率。
- 支持拖动、滚轮缩放、触摸拖动、双指缩放、缩放百分比、恢复 100%、适应画布、小地图。
- 跨章搜索章节名、考点标题与正文，支持多个关键词。搜索定位会自动打开祖先分支。`/` 聚焦搜索，Enter 打开首个结果。
- 脑图与大纲共享展开和阅读状态；大纲适合连续阅读和键盘操作。
- 桌面使用独立阅读侧栏；手机将考点笔记放在下方，同时保留当前节点可见区域。
- 已按最新要求移除知识图谱全屏入口及原生 Fullscreen API；页面内的专注阅读仍可使用。iOS 适配和本轮回归记录见 `knowledge-sprint-notes.md`。
- 练习入口明确按“本章”出题，使用已有章节范围；不将整章题量错误标注为单个考点题量。

## 组件选择

| 方案 | 官方能力与适用场景 | 本项目取舍 |
| --- | --- | --- |
| [React Flow](https://reactflow.dev/learn/concepts/built-in-components) | React 自定义节点、可交互画布、Background、MiniMap、视口控制 | 采用 `@xyflow/react` 12.11.6，复用画布和小地图，学习节点和阅读区沿用项目组件与样式 |
| [AntV G6](https://g6.antv.vision/en/manual/getting-started/integration/react/) | 图可视化引擎，可在 React 中集成 Graph 实例 | 可用于更复杂关系网络；当前章、节、考点树不需要额外的图分析层 |
| [Markmap](https://markmap.js.org/docs) | 从 Markdown 生成交互式脑图，提供 React 示例 | 适合以 Markdown 为源的展示；本项目直接使用结构化考点数据并连接练题交互 |

以上取舍是基于现有 React 应用、结构化知识数据和练习入口的工程判断。未引入付费模板；React Flow 包使用 MIT 许可，通过 `proOptions.hideAttribution` 关闭画布署名，发行文件保留完整许可证。树结构布局由小型纯函数负责，避免为固定的三个层级再引入布局引擎。构建仍是单文件 PWA，新增组件使 gzip 产物从约 728 kB 增至约 800 kB。

## 复现自测

```sh
npm run build
npm run test:knowledge
npm run test:quality
npm run test:knowledge:browser
```

浏览器脚本直接打开构建后的 `dist/index.html`，也可通过 `KNOWLEDGE_TEST_URL` 指向本地服务。需要安装 Python Playwright、Chrome 和 WebKit 浏览器。

- 单元与数据回归：26 章一一对应、170 组考点可达、布局无同列重叠、总览章序、跨章正文检索、祖先展开和收起边界；原有归类与内容质量检查保持通过。
- 浏览器矩阵：Chrome / WebKit，各测桌面 1440×1000 和手机 390×844；另检验 360×640、844×390。
- 核心流程：展开收起、适应画布的节点边界、缩放拖动、小地图、空搜索恢复、跨章定位、详情无页码、焦点、大纲切换、切科目、明暗主题、章节练习、退出与返回。
- 手机额外检验触摸点击；Chrome 通过浏览器设备模拟接口发送触摸拖动及双指缩放事件。设备模拟不等同于物理手机验收。
- 截图与测试结果写入忽略提交的 `tmp/knowledge-ui/`。


## 点击与屏效修正

- 修复只读节点继承 `pointer-events: none`，导致鼠标点击穿透到背景画布的问题；节点内容显式恢复命中，按钮同时标记 `nodrag nopan`。
- 默认显示本章考点。节点从 280×100 压缩为 232×64，行距由 126 改为 80，列距由 360 改为 276。去掉重复的节点类型和阅读提示，正文仍保留可读字号。
- 合并紧凑的章节上下文，降低顶栏和目录行高；中等宽度的阅读区参与布局，不覆盖脑图。
- 自测补充直接点击脑图加号、减号、考点正文，以及实际坐标命中检查，防止搜索、大纲的成功掩盖画布交互失效。


### 按文字尺寸收紧节点

按用户明确要求保留原有连接线和图谱层级。节点不再统一使用大矩形：宽度依据标题估算并限制在 92–250 像素，短标题高度 32 像素，长标题按行数增高。布局按子树实际高度分配空间，避免长标题节点重叠。摘要不放进节点，阅读详情按内容高度收缩，并将题量并入练习按钮。


### 全科统一脑图

每个科目只有一张脑图：科目一 8 章、科目二 18 章始终保留，章节标题使用“一、标题”至“十八、标题”。默认先看全部章节，再逐章展开；多章可以同时展开。目录只定位章节，搜索自动打开祖先分支，均不会过滤其他章节。“展开全部 / 收起全部”控制整科知识树。中文编号只用于展示，不改题库章节名称或练习范围。
