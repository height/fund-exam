# 小抄样式基础规范（2.0）

以 2026-09-21 确认的两份 2.0 小抄为基准。所有科目共用 `src/lib/notebookPrint.css` 和 `notebookPrintControls.js`；预览、独立 HTML 下载和打印使用同一模板。更新模板后重新打开应用中已保留的小抄即可应用；已经下载的 HTML 不会自动更新。

## 信息层级与留白

| 层级 | 规范 |
| --- | --- |
| 页面 | A4 纵向，8mm 页边距，双栏，4mm 栏间距；正文 7.5pt、行高 1.48 |
| 章节标题 | 深蓝底 `#244d70`、白色粗体、8.3pt；上/下间距 2.3/1.2mm，内边距 0.9mm 1mm |
| 知识点标题 | 浅蓝底 `#e3edf8`、深蓝字 `#163e65`、8pt 粗体；左侧 2.2pt 蓝线 `#3976ac`；内边距 0.75mm 1mm |
| 知识点编号 | 深蓝底 `#315f89`、白字；连续编号，与正文内容无关 |
| 知识块 | 下外边距 1.6mm、下内边距 1.1mm，细分隔线 |
| 段落与列表 | 段落上下 0.55mm；列表项上下 0.35mm |
| 表格 | 7pt、行高 1.44，单元格内边距 0.55mm 0.65mm；浅灰蓝表头 `#eef2f6`，自动列宽 |

章节、知识点、表头必须一眼可区分。保持信息密度，允许自然增加页数，不通过缩小正文或删除内容强行凑页。

## 三色笔与图形

- 蓝 `#245b9a`：核心结论；绿 `#24704f`：条件；红 `#a33432`：易错与例外。黑色正文为主，少量标记关键短语。
- 原图与公式完整保留。SVG 画布和全画布背景矩形统一白色，图中节点填色、线条、文字仍保留原来的语义颜色；只改变导出副本，不修改源笔记。
- 图形等比例适配栏宽，高度上限 45mm；不裁切、不拉伸、不放大位图。手机缩放整张 A4，不重新挤排文字。
- 公式使用原有数学渲染，不转成图片；较长公式或图形应在实际预览中确认无溢出。

## 分页与打印

- 普通知识块尽量不拆分；屏幕布局高度超过 360px 的长块可自然跨栏/跨页。表格行、图片及公式尽量保持完整，表头跨页重复。
- 页底居中使用 `@page @bottom-center` 输出“第 X 页 / 共 Y 页”。需使用支持 CSS 页边距盒及页码计数的浏览器；以 Chrome 打印验证。
- 打印隐藏工具栏、审核说明和末尾统计，避免统计单独占用空白页；品牌标识位于右下角，3mm 图标、6pt 字号。
- 打印选择 A4、彩色、100% 缩放，关闭浏览器自带页眉页脚。连续屏幕预览不显示分页页码，打印预览/PDF 显示。

修改共享样式后检查两科代表性长文、表格、SVG、公式及移动端预览，确认标题层级、白底图、完整性和页码，再运行构建。
