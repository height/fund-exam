# 笔记本

## 创建与编辑

长按选中文字并点“记笔记”只生成内存草稿，不请求 AI、不写入 IndexedDB。摘录回执复用编辑对话的输入组件，用户可以描述希望记录的内容，或展开查看来源。

首次创建：发送要求后打开“新建笔记”，展示“选中原文 / 待保存”两个 Tab。AI 结合选区、题目答案与上下文给出预览；只有点击“加入笔记本”才保存。取消或关闭未保存预览不新增笔记。

二次编辑：已有笔记打开“编辑笔记”，展示“原笔记 / 修改中”。问答不改存储，修改建议经“保存修改”确认后提交；校验版本以避免覆盖并发修改。依据不足的结果标为待核对，人工核对后可收进精华。

原文、章节和每次摘录时间随确认保存保留。关联考点可由 AI 比较并提出合并建议，明确确认才合并。旧笔记与旧待处理状态继续兼容。

## 内容与界面

通用 Markdown 正文支持标题、列表、表格、公式、SVG、图片和高亮。公式以 KaTeX 转 MathML；HTML/SVG 净化后呈现，不执行模型脚本。三色笔用低饱和蓝、青绿和暖褐区分结论、条件与例外，默认只标少量短语。旧结构化公式与图示继续展示。

手机竖屏使用紧凑列表与三行摘要，完整知识不被删减。共享浮层支持原文和修改预览切换、对话连续编辑、未保存保护与焦点恢复。桌面分栏，手机分区滚动并适配可视视口。语音按钮仅提示“尽请期待”；原有朗读服务保留。

## 验证

- `npm run build`：内容检查和生产构建。
- `node --test tests/notebook.test.js`：笔记数据、依据和 Markdown 校验。
- `python3 tools/test_note_dialog.py`：Chrome/WebKit，首次创建不自动保存、回执指令传递、确认入库、二次编辑、取消、主题、Markdown、移动端筛选及布局。AI 使用模拟响应，不代表真实模型准确度。

对话使用真实 SSE 回复：先显示像素等待状态与耗时，收到顶层 reply 字段后逐段渐显正文。JSON 转义和跨块 Unicode 在解码后展示；笔记仍须完整返回、校验并由用户确认保存。停止或失败保留已收到的文字并标记未完成，未完成内容不生成笔记预览。向上阅读历史时暂停自动跟随；减少动态效果设置关闭渐显和光标动画。

共享输入框根据内容与宽度自动伸缩，最多三行，超出后内部滚动；快捷填入、收起/展开与发送清空均重新测量。选区操作支持“解释 / 记笔记 / 复制”，复制成功或失败提供反馈。

## AI 彩色 A4 小抄

笔记本顶部“小抄”使用当前配置的 AI 提炼全部已整理精华（不受当前搜索筛选影响，排除待核对笔记）。按章节分批，每批最多 8 条、通常不超过 16000 字符；单条长笔记不截断。AI 合并重复、删除非必要案例、生成层级短句/表格/公式/静态小图，保留条件、例外与关键数值。输出必须标注源笔记 ID，全部来源被覆盖后才生成预览；这一检查不等于语义准确性保证，打印前仍应核对。原笔记不变。

默认双栏图文速记，可切换三栏；A4、8mm 页边距、8pt 正文，紧凑章节色带与表格。蓝色结论、绿色条件、红色易错，以黑色正文为主。屏幕连续预览不撑出大块空白；打印按 A4 自动分页。资料少时不虚构内容填满纸张。

固定功能页显示真实批次与接收进度，支持取消和离开中止；缺少 AI 配置、接口失败、格式错误或来源遗漏时提示重试，不回退到原文直排。总时限五分钟。

支持打印/另存 PDF，以及下载带内置样式与操作脚本的独立 HTML。远程图片需要联网，未加载时提示检查。打印建议开启彩色、关闭浏览器页眉页脚并用 100% 缩放。验证：`node --test tests/cheatsheet.test.js` 与 `python3 tools/test_notebook_print.py`。浏览器测试使用模拟 AI，覆盖三色样式、分批生成、取消/失败、独立 HTML 和多页 A4 PDF，不代表真实模型的提炼质量。

小抄生成成功后将独立 HTML、精炼内容、生成时间与源笔记指纹写入 IndexedDB `kv` 的 `notebook-cheatsheet:last`。顶部“小抄”进入固定功能页 `#/cheatsheet`，展示缓存，不调用 AI；“重新生成”成功才覆盖旧版本，失败/取消保留旧版本。源笔记变化时显示提示。缓存打开时用保存的精炼内容重新渲染当前模板，既应用打印修复，也不直接执行导入或篡改的缓存 HTML。保存失败时仍允许预览下载并提示用户。此功能启用前的未保存窗口不属于已有缓存。

打印与预览统一使用均衡分栏，少量内容不再全部挤入第一栏。CSS 保留三色笔；系统打印窗口仍须选择彩色，应用不能覆盖打印机的黑白设置。

小抄功能页负责生成、进度、错误处理与上次结果管理。生成完成只保存并展示结果卡，不自动弹出窗口；用户点击“查看 / 打印”才打开独立临时预览。刷新固定页面恢复 IndexedDB 结果；离开页面取消进行中的请求，已有结果保留。
