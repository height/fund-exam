# 笔记本

## 创建与编辑

长按选中文字并点“记笔记”后自动发送“整理这个知识点”，以收起的输入浮条展示进度；生成过程只保留内存草稿，点击“加入笔记本”才写入 IndexedDB。浮条可继续补充要求或展开查看来源与预览。

首次创建：自动整理后可展开“新建笔记”，展示“选中原文 / 待保存”两个 Tab。AI 结合选区、题目答案与上下文给出预览；只有点击“加入笔记本”才保存。取消或关闭未保存预览不新增笔记。

二次编辑：已有笔记打开“编辑笔记”，展示“原笔记 / 修改中”。问答不改存储，修改建议经“保存修改”确认后提交；校验版本以避免覆盖并发修改。依据不足的结果标为待核对，人工核对后可收进精华。

原文、章节和每次摘录时间随确认保存保留。关联考点可由 AI 比较并提出合并建议，明确确认才合并。旧笔记与旧待处理状态继续兼容。

## 内容与界面

通用 Markdown 正文支持标题、列表、表格、公式、SVG、图片和高亮。公式以 KaTeX 转 MathML；HTML/SVG 净化后呈现，不执行模型脚本。三色笔用低饱和蓝、青绿和暖褐区分结论、条件与例外，默认只标少量短语。旧结构化公式与图示继续展示。

手机竖屏使用紧凑列表与三行摘要，完整知识不被删减。共享浮层支持原文和修改预览切换、对话连续编辑、未保存保护与焦点恢复。桌面分栏，手机分区滚动并适配可视视口。语音按钮仅提示“尽请期待”；原有朗读服务保留。

## 验证

- `npm run build`：内容检查和生产构建。
- `node --test tests/notebook.test.js`：笔记数据、依据和 Markdown 校验。
- `python3 tools/test_note_dialog.py`：Chrome/WebKit，首次创建不自动保存、回执指令传递、确认入库、二次编辑、取消、主题、Markdown、移动端筛选及布局。AI 使用模拟响应，不代表真实模型准确度。

对话使用真实 SSE 回复：先显示像素等待状态与耗时，收到顶层 reply 字段后逐段渐显正文。JSON 转义和跨块 Unicode 在解码后展示；笔记仍须完整返回、校验并由用户确认保存。停止或失败保留已收到的文字并标记未完成，未完成内容不生成笔记预览。向上阅读历史时暂停自动跟随；减少动态效果设置关闭渐显和光标动画。

共享输入框根据内容与宽度自动伸缩，最多三行，超出后内部滚动；快捷填入、收起/展开与发送清空均重新测量。选区操作支持“解释 / 记笔记 / 复制”，复制成功或失败提供反馈。

## AI 彩色 A4 小抄

笔记本顶部“小抄”使用当前配置的 AI 提炼全部已整理精华（不受当前搜索筛选影响，排除待核对笔记）。按章节分批，每批最多 8 条、通常不超过 16000 字符；单条长笔记不截断。AI 合并重复、删除非必要案例、生成层级短句/表格/公式/静态小图，保留条件、例外与关键数值。输出必须标注源笔记 ID，全部来源被覆盖后才生成预览；这一检查不等于语义准确性保证，打印前仍应核对。原笔记不变。

默认双栏图文速记，可切换三栏；A4、8mm 页边距、8pt 正文，紧凑章节色带与表格。蓝色结论、绿色条件、红色易错，以黑色正文为主。屏幕连续预览不撑出大块空白；打印按 A4 自动分页。资料少时不虚构内容填满纸张。

固定功能页显示真实批次与接收进度，支持手动取消，站内切页继续生成；缺少 AI 配置、接口失败、格式错误或来源遗漏时提示重试，不回退到原文直排。总时限二十分钟。

支持打印/另存 PDF，以及下载带内置样式与操作脚本的独立 HTML。远程图片需要联网，未加载时提示检查。打印建议开启彩色、关闭浏览器页眉页脚并用 100% 缩放。验证：`node --test tests/cheatsheet.test.js` 与 `python3 tools/test_notebook_print.py`。浏览器测试使用模拟 AI，覆盖三色样式、分批生成、取消/失败、独立 HTML 和多页 A4 PDF，不代表真实模型的提炼质量。

小抄生成成功后先展示待保留预览；点击悬浮条“保留”才将独立 HTML、精炼内容、生成时间与源笔记指纹写入 IndexedDB `kv` 的 `notebook-cheatsheet:last`。顶部“小抄”进入固定功能页 `#/cheatsheet`，展示缓存，不调用 AI；新结果确认保留后才覆盖旧版本，丢弃/失败/取消均保留旧版本。源笔记变化时显示提示。缓存打开时用保存的精炼内容重新渲染当前模板，既应用打印修复，也不直接执行导入或篡改的缓存 HTML。保存失败时仍允许预览下载并提示用户。此功能启用前的未保存窗口不属于已有缓存。

打印与预览统一使用均衡分栏，少量内容不再全部挤入第一栏。CSS 保留三色笔；系统打印窗口仍须选择彩色，应用不能覆盖打印机的黑白设置。

小抄生成任务由 App 全局持有，站内切页或返回笔记本不会中断请求，生成页重新进入时恢复同一进度。全局胶囊悬浮条显示生成中，点击返回进度页；完成后提供保留、丢弃、重试及查看入口。浮条避开底栏、计算器和收起的笔记浮层。请求使用开始时的笔记、Prompt 与思考档位快照，禁止重复启动；重试沿用该快照。生成完成不自动弹出窗口；用户点击“查看 / 打印”才打开独立临时预览。刷新或关闭浏览器不支持后台续传，重新打开恢复已确认保存的 IndexedDB 结果。验证：`node --test tests/cheatsheet-task.test.js` 与 `python3 tools/test_cheatsheet_background.py`（模拟 AI，覆盖跨页生成、保留/丢弃、失败重试与取消）。

## AI 回复格式兼容

统一按 SSE 事件读取流，支持跨字节 UTF-8、CRLF、多行 data、注释/元数据，以及 EOF 无换行的末段；兼容返回普通 JSON completion 的服务。明确区分输出长度上限、服务端错误和损坏的数据流。

结构化回复允许外围说明/代码围栏、尾逗号、原始换行与 SVG 引号等可修复语法错误，保留 LaTeX 反斜杠。只对闭合的数据结构尝试修复；截断字符串、未闭合对象、缺失字段值和省略内容不补全。修复后继续执行原有笔记/小抄来源及结构校验。测试：`node --test tests/ai-response.test.js`，浏览器用带注释、尾部无换行和代码围栏的受控响应回归。

小抄的科目信息只在文档页头显示（多科目并列）。正文按原章节顺序连续排列考点，不输出科目/章号/章节名分组标题；AI 标题与正文也不添加这类归属标签。重新打开缓存即可使用新排版，无需重新调用 AI。

手机小抄预览保留固定 A4 排版，默认等比适应屏幕，支持 100% / 150% 放大及横向滚动；缩放不改变正文换行，打印恢复原始尺寸。

小抄按科目整体组织知识关系，不再以章节或固定条数分批直接拼接。超过请求预算的资料先提炼，再进行跨批整体合并，来源覆盖逐层校验。每个知识块尽量完整换栏/换页，只有超长块允许自然拆分。旧缓存重新打开可使用新的排版，内容合并需点击重新生成。

笔记首次创建、对话修改与小抄生成共用极简蒸馏规则：默认一行核心结论，必要时补充条件和易错区别；删背景、复述和非必要演算，跨笔记去重。复杂知识保留不可删除的判断要素，用户要求展开时遵从；不以硬字数裁剪或丢失限定条件换取短小。已有笔记不自动改写，需对话修改或重新生成小抄。

小抄文字极简提炼时，已有图片、SVG、公式优先保留；解析生成结果后校验 Markdown 图与公式并补回遗漏项，图形按原比例适配栏宽，沿用三色语义。新建笔记以用户明确要求和选区为主题，上下文只辅助消歧、章节识别与提供直接依据，不扩展到相邻无关考点。

笔记对话提供持久化的思考开关，开启时请求 thinking.enabled + reasoning_effort=max，小抄默认 MAX。结构化任务显式使用 JSON 输出格式和输出预算；格式不完整时仅自动重新生成一次，取消和网络错误不重试，完整校验后才显示修改建议。状态可折叠，显示实际接收和重试状态，不模拟思考过程。MAX 笔记等待上限10分钟，小抄20分钟，随时可停止；第三方接口不支持参数时显示服务错误，不静默降级。生成SVG默认不透明浅色背景，图示容器也提供白底，保证暗色及打印可读。

对话失败提示按主动停止、超时、连接中断、输出截断、服务错误、结果校验失败区分，并保留具体原因。部分自然语言回复不代表完整笔记数据已成功，失败轮次不生成新预览也不覆盖旧笔记；未校验的部分回复不再传给下一轮模型。

思考入口更新为 OFF / LOW / MEDIUM / HIGH / MAX 下拉选择，笔记和小抄均默认 MEDIUM，分别记住用户选择，请求期间禁用切换。SVG 在 Markdown 解析前作为完整块隔离，避免空行和缩进把子节点拆成段落或代码块；背景必须先于图形绘制。

章节精华、待处理、时间索引统一只显示笔记标题和必要状态，右侧 SVG chevron，整块点击进入共享详情浮层；时间索引保留时间定位。移除独立查看/编辑按钮，详情浮层上方露出部分原页面。

小抄生成规则外化为独立默认模板，在生成页可编辑、保存、取消修改和恢复默认。本地只保存规则模板；编辑器不拼接或展示笔记正文、摘录、上下文。动态笔记材料仅在实际生成请求时加入，输出协议与来源校验由程序附加。未保存的Prompt修改会阻止生成，保存后各批与合并步骤使用同一份规则快照。

笔记生成以“脱离本题仍可复用”为默认目标：所选主题定范围，解析提供规则依据，移除题设实例，保留改变结论的条件与例外，最后精简表达。计算题保留符号关系而非代入结果，选择题保留决定正误的区别而非逐项点评；证据引用仍完整保留在 evidence 中，不要求正文照抄情境。不从单例泛化；笔记可从相关图谱和可靠基础通识补足规则，确有不确定性时才标记待核对。用户明确要求示例或推导时允许保留并注明。规则应用于新建、对话修改以及小抄默认提炼规则，不自动改写已保存笔记。

笔记默认展示顺序为“一句话（必要时多句话）＋可选表格＋可选公式＋可选图”。各形式按表达需要独立选择，避免重复信息和占位栏目。三色语义不变：蓝色核心结论、绿色条件、红色易错；少量按需标记，不要求三色齐全，也允许不标色。


笔记知识补充：新建、摘录整理和对话修改都会在所选科目的图谱中检索相关考点（最多4条、每条1800字），把条目内容及其章节交给 AI，用于自动归类和补全定义、条件、公式、易错点。图谱材料与原始摘录分开保存，在“依据”及笔记详情中可查看。科目仍由用户决定。

每个要点用 `evidenceKinds` 区分原文（source）、图谱（graph）与可靠基础通识（common）；原文及图谱引用须能在相应资料中找到，通识允许没有逐字引用，不因选区只含一个术语就要求补依据。确有资料冲突、事实不确定、关键条件缺失，或现行政策/产品条款/实时数字缺少适用依据时仍标为待核对。旧笔记没有类型字段时沿用原文引用校验。

验证：`node --test tests/notebook.test.js tests/notebook-knowledge.test.js`；`python3 tools/test_note_create.py` 覆盖移动端与桌面端的图谱补充、预览确认、持久化及依据展示（模型回复使用受控数据）。

收起态采用紧凑圆角输入条，整理时显示“正在整理「摘录内容」到笔记中…”。拖动手柄支持鼠标、触控和方向键；位置限制在可视区域内，避开底部操作栏、导航与计算器，并在展开/收起之间保留位置。键盘或窗口尺寸变化时重新约束位置，正文输入和发送不会触发拖动。
