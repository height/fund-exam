## 可重放的修复与防回退

- `tools/question-material-repairs.json`：材料原文、原题面、PDF文件和物理页码。
- `tools/question-content-repairs.json`：每个字段的旧值、新值、原因、来源和内容版本；含隔离题原因。
- `tools/question-cleanup-repairs.json`、`tools/question-source-repairs.json`：页码、串题及原件核对后的修订。
- `tools/question-plain-repairs.json`：同步白话解析的旧值、新值或移除理由。
- `npm run repair:questions` 可以重放已确认修订；遇到清单之外的新改动会拒绝覆盖。材料重放不会降低后续内容版本。
- `npm run build` 检查非空解析、有效答案、四个不同选项、科目章节合法性、ID唯一性、同科题干+选项完全重复、材料引用、组合选项缺陈述、广告页码及派生索引；并校验已确认修订和白话解析未被重新导入覆盖。
- `npm run audit:questions -- --output <报告路径>` 输出全库覆盖、待核查题及相似候选；阈值候选只用于审读，不自动删除。
