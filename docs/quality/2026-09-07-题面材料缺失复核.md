## 防复发

1. `question_materials.py` 保留原题号、源文件及材料组范围；看到“回答25—27题”时整组进入待核对，包含未重复写材料引用的小题。
2. 抽取和合并阶段将未核实材料题保存在 `tmp/pending-materials.json` 或 `tmp/distill/pending-materials.json`，不进入可计分题库。有源答案或两次作答一致也不能绕过。
3. 核实后将文字/表格和问题一起存入题干；练习、考试、错题、朗读与AI读取的是同一完整题面。展示层将材料排成表格，不依赖前一道题，不折叠关键条件。
4. `npm run repair:materials` 按复核清单恢复题面；原题发生意外变化时拒绝覆盖。
5. `npm run build` 先运行材料检查。待核实标记、裸表图引用或已核实题面被覆盖都会阻止构建。规则检查无法证明所有题语义无误，新增题仍需独立审题。
