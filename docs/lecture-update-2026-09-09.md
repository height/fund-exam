# 讲义驱动的章节、图谱与归类更新（2026-09-09）

依据用户提供的《科目一讲义.pdf》（151页）与《科目二讲义.pdf》（172页）的正文整理。科目二导学中的2017版章节分布只作历史对照，不进入目录生成或归类检索；采用2025版教材章序，并用仓库内2026年度修订大纲补齐节名。

## 本次结果

- 科目一8章、科目二18章；章名和章序经核对保持新版体系。
- 补齐两科113节，整理170组学习要点（科目一66组、科目二104组）。知识图谱统一为章—节—考点，补上原图谱缺失的行业文化、合规内控、另类投资、投资管理流程、销售等独立分支，并将风险、业绩、募集、结算、估值、分配、披露拆回各自章节。
- 图谱直接使用题库章名关联正确率和章节练习，移除旧别名映射及跨章null映射；切科目时清空展开和详情状态。
- 按用户要求，章节页面和考点详情不显示讲义页码；资料定位仅供内部内容审计使用。
- 对全部1663题执行结构检查和讲义正文文本检索，记录51项重点复核决策：27题调整（科目一14、科目二13）、20题保留、4题待复核。其余题目的检索状态为screened，不代表逐题人工核准，也不等于归类准确率。
- 仅更改27题的chapter并同步章节索引；题目ID、科目、题干、选项、答案、解析、内容版本与材料复核字段逐题比对均保持不变。旧练习记录继续按ID关联。

检索只用于召回候选。嵌入图片中的公式不参与文本相似度计算；收益率、捕获率和风险调整收益等图示已单独渲染核对。未确认的候选不会自动落入新章节。

## 归类边界

优先看决定答案的主考点，不能只看材料背景或解析相似词。监管机关职责和基金机构具体义务分开；主体准入治理、具体业务规范和职业道德辨识分开。科目二中，指数与基准选择归投资管理流程，组合构建和免疫策略归投资组合管理，风险测度归投资风险管理，风险调整收益归业绩评价，投资者目标和销售策略归销售基础知识。重复出现在多章的相关系数、β、QDII计价货币等，保留合理主章并记录理由。
