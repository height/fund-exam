# 公式攻坚微课堂

## 内容与边界

首期六节课覆盖收益金额、持有期收益率、单利对照复利、复利现值、组合加权收益和概率期望。每节有四个带练步骤、三项独立能力，每项有三道独立测评题和三道隔日复查题，共 108 道自编测评题，另有 12 道带练题和四道基础诊断。

新课程入口为 `#/formula`，课程链接为 `#/formula?unit=<id>`。`#/formula?mode=reference` 保留原 47 组公式和变体的查阅；旧版勾选只能作为历史记录。原来的固定单题测验不在查阅模式中继续授予掌握标记。

课程目标为单节约 5–8 分钟，这是设计目标，尚未经过真人用时验证。

## 教学和状态规则

从具体金额建立中文关系，再对应数字算式与教材字母。学生逐步从示范、带练进入关系判断、独立计算与情境迁移。三种图解为资金收支、逐期账本、资金/概率分配和贡献明细；键盘、数字输入、单选和滑块均可完成操作，无必需拖拽。

独立测评收起示范、账本和公式。第一次回答正确且此前未看提示或答案，才成为独立证据。答错再修正不会改写第一次回答；题目用完会说明没有新题。系统不会通过重复做已见过的题增加掌握记录。

三项独立测评通过后为“能独立完成”，从最后一项通过起计 24 小时，在下次打开时推荐复查；三项隔日新题通过后为“已巩固”。复查失败会撤销该维度通过状态，重新独立完成该维度后再等待 24 小时。没有外部提醒。

## 代码职责

- `src/data/formulaCourses.js`：CourseUnit 课程、带练、诊断、独立和复查题、明确的旧公式/题库映射。百分比在计算模型中统一为小数。
- `src/lib/formulaMath.js`：收益、增长、折现、加权计算；带单位的输入与舍入；中文/数字/字母共用的数学表示树。
- `src/lib/formulaProgress.js`：纯 reducer、证据重放、首次作答规则、延迟复查、版本校验和幂等合并。
- `src/lib/formulaStorage.js`：顺序写入 IndexedDB；页面卸载时已经排队的写入继续，读取会等待写入队列。
- `src/views/FormulaClassroom.jsx`：学习路径、诊断、补课、单步课堂、反馈、复查和续学。
- `src/components/formula/FormulaScenes.jsx`：三类数量图解和结构化公式呈现。

学习记录位于 IndexedDB `fund-quiz/kv` 的 `formula-course-progress-v1`。备份包括独立字段 `formulaProgress` 和原有 `kv` 条目。导入优先读取独立字段，也支持只含 `kv` 的备份。合并按不可变作答 ID 去重，重新计算状态；旧备份覆盖会清空新课记录，合并则保留。仅恢复新课程对应的 kv 记录，不顺带覆盖 AI Key 或其他设置。保存成功以事务提交为准，失败显示重试入口。

题库定向练习使用 `scope=formula:<unitId>`，只映射已人工核对的科目二题。复利映射包含原计算题标签遗漏的 `572e7cb191de`。现值和概率期望暂未找到适合作为直接配套题的已核对题，显示自编题说明，不使用不相关题凑数。普通题库作答继续写入原有记录与错题本，不提升课程状态。

## 工程验收

```sh
node --test tests/formula.test.js
npm run build
python3 tools/test_formula_webkit.py
```

浏览器回归需要本机已安装 Python Playwright、WebKit 与 Chromium。脚本使用临时本地 HTTP 服务运行生产构建，阻止外部请求。覆盖六节课、引导步骤、三种公式表示、填写后刷新、独立判定、隔日复查、导入导出、科目二定向练习、旧目录、离线 Service Worker、保存失败与重试。WebKit 用于交互回归；当前 WebKit 的模拟离线重载会报告浏览器内部错误，因此生产 Service Worker 的真实离线重载另由 Chromium 验证。检查 320、390、768、1280 像素宽度，并生成 `/tmp/formula-*.png` 截图供人工检查。
